# Software Engineering Search Engine

A coursework repository for the design and development of a search engine, organized into four software engineering laboratory stages.

## Labs

1. **[Lab 1 – Requirements Engineering](Lab-1-Requirements-Engineering/requirements.md):** project scope, stakeholders, functional and non-functional requirements, and acceptance criteria.
2. **Lab 2 – System Modelling:** domain model, sequence diagrams, and class diagram.
3. **[Lab 3 – Design Patterns](Lab-3-Design-Patterns/README.md):** implementation and discussion of selected design patterns.
4. **[Lab 4 – REST API](Lab-4-REST-API/README.md):** REST API implementation and API documentation.

## Getting started

Each lab directory contains its own deliverables and notes. Add diagrams and source files to the corresponding directories, and update the relevant lab README as work progresses.

## Status

This repository is an initial coursework scaffold. Requirements, models, implementations, and API details should be completed and validated as part of the labs.
